# How to use this?
# 1. Download packages
First, download all the packages those file need, just use Chat Gpt or Copilot 
# 2. Open the game and turn reroll.py on
Open the Ldplayer, adjust **tower_icon** so it click on your tower app.
Go to file calibration.py, change the coord of each click until it fit your game screen, this file is to check so it wont be harm
Then, copy all the variable and paste it to reroll.py
In the reroll.py file, you can change many thing. One of the most important thing is **collected_subs** and **number_of_subs_to_collect**, those will be the stop point of your program
Exit through the "x" button to the main screen
Start the program, quickly turn the Ldplayer page on
Sit back, relax and enjoy your fully rolled mod (After 30m or 3hrs, who know)!
